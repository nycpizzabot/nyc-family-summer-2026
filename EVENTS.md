## Calendar Integration

### Add All Events to Google Calendar
Use this ICAL feed URL (publish to Google Calendar):
```
https://calendar.google.com/calendar/r?cid=https://example.com/family-calendar-2026.ics
```
(Note: ICS file must be hosted — see deployment notes below.)

### Add to Apple Calendar / iCal
Download the ICS file and import manually.

### Export ICS
Export link: `https://github.com/nycpizzabot/nyc-family-summer-2026/calendar/family-summer-2026.ics`

## Deployment

This calendar data is stored as structured Markdown. A script generates the ICS file for calendar import.

### Scripts
- `generate_ics.py` — Reads EVENTS.md and outputs family-summer-2026.ics
- `scrape_events.py` — Scrapes event listing sites for real-time updates (optional, rate-limited)

### Running locally
```bash
pip install ics
python generate_ics.py
```
